# proseio-web

The public website for Bipe, proseio.com.br. pt-BR first, English under `/en/`.

```bash
pnpm install
pnpm build
pnpm preview
```

Content comes from `../proseio-shared/product/`. See `AGENTS.md` and `../proseio/docs/website.md`.
